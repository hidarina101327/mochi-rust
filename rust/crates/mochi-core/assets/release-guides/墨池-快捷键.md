## 常用快捷键
墨池基于用户的使用习惯，支持一系列常用的快捷键，您也可以在设置中修改
### 原生MD支持的快捷键
~~~
# 标题
- 无序列表
1. 有序列表
> 引用
- [ ] 待办事项
`行内代码`
``` 代码块
~~~
Ctrl+B：加粗
Ctrl+I：斜体
Ctrl+U：下划线
Ctrl+Shift+B：插入代码块
Ctrl+Shift+8：插入无序列表
Ctrl+Shift+9：插入有序列表
Ctrl+Shift+7：插入待办事项
Tab：增加列表层级
Shift+Tab：减少列表层级

### 文档编辑快捷键
支持常见场景的文档编辑快捷键，如：
<code>Ctrl+Z</code>：撤销操作
<code>Ctrl+Y</code>：恢复操作
<code>Ctrl+F</code>：查找内容
Ctrl+V：带格式粘贴内容
Ctrl+Shift+V：纯文本粘贴内容

### 墨池自定义的快捷键
Ctrl+J：呼出/关闭侧边栏
Ctrl+\\：展开/折叠左侧边栏
Ctrl+N：新建文档
Ctrl+P：快捷打开页面
Ctrl+Shift+P：快捷打开命令行
<code>Ctrl+Alt+S</code>：打开日程
<code>Ctrl+Alt+D</code>：打开仪表盘
<code>Ctrl+Shift+F</code>：全局搜索
<code>Ctrl+Shift+L</code>：切换深色模式
Ctrl+Shift+Space：呼出捕获窗口
> 注：部分快捷键可能会受到操作系统、浏览器或输入法设置的影响。
