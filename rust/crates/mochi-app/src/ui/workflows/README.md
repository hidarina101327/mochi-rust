# Rust 自动化画布

原生 Direct2D 画布与 Electron Workflow 编辑器采用相同的主要操作方式：分类卡片、关键参数预览、曲线连线、条件分支端口、可调整宽度的配置面板、节点库搜索/点击/拖入、连线中间插入、撤销重做、缩放、适配、自动布局和可点击缩略图。

节点参数按现有 `inputs` / `config` 字段生成表单，保留布尔值、数值、对象等原始类型；复杂配置仍可切换到高级 JSON。编辑器复用原生 TextField，因此中文输入法、选区和剪贴板走现有路由。切换节点和保存前应用参数，非法内容保持在当前字段，未保存草稿包含字段路径，避免恢复时写入错误位置。AI 节点可选择已配置的模型提供商，文本字段可从菜单插入工作流输入、日期和已连接的上游输出。

空白拖动平移，滚轮缩放；节点拖动吸附 16 DIP 网格；自动布局按 DAG 拓扑层级排列，属于一次可撤销操作。自连接、重复连接和循环连接不会修改图。缩略图点击定位，右侧面板左边缘可拖动调宽。运行历史使用只读快照。

## 格式边界

本模块继续使用 Rust 执行引擎的 `mochi.workflow` 契约和 Store，保留版本冲突校验、定时、运行历史、草稿恢复。保存及导入的工作流作为可信脚本执行，运行和启用定时没有二次授权弹窗。Electron 的 `mochi.workflow-canvas` / `.mcanvas` 是另一种编辑器文档，没有转换两者。原有普通引用画布不受影响。

## 验证

`cargo test -p mochi-app workflows -- --test-threads=1` 覆盖图编辑、参数类型、恢复草稿、变量/提供商选择、原生 IME、保存授权执行和布局。设置 `MOCHI_WORKFLOW_TEST_ARTIFACTS` 可输出 1440 / 1100 / 800 宽度的浅色、深色 Direct2D 截图。

## 第二轮界面对齐

宽窗口使用常驻左侧节点库、紧凑顶部操作区和右侧配置 / 运行记录页签。配置按基本设置、节点参数、输入变量和运行设置分组，布尔字段使用开关，固定选项使用下拉菜单；开始节点直接编辑手动、每日、每周、间隔触发规则。下拉选项以 Rust 引擎实际支持的能力为准。

所有缩放比例保留图标、类型和参数预览，文字与卡片等比例缩放。检测旧节点间距重叠时进行一次可撤销布局整理，保存后才持久化。Shift 点击 / 框选和 Ctrl+A 支持多选，拖动与删除整体撤销。

回归还覆盖 11 节点、条件双分支、54% 缩放的原生渲染，截图为 `workflow-eleven-54.png`。

## 文件夹与变量端口

`library.rs` 绘制自适应卡片网格、文件夹导航和名称编辑。文件夹与流程归属独立存储于 Store，不修改工作流定义或执行版本；删除文件夹保留其工作流。

`ports.rs` 使用现有输入引用表示数据连线。拖动输出到具体输入会将 `$nodes.ID.output.FIELD` 写入该输入，并补充执行依赖；多个输入可引用同一输出，共用依赖边。灰色执行连线和蓝色变量连线分别可选中、右键删除与撤销。配置字段内提供可搜索变量选择和自定义值编辑，数值、对象等输入仍保留 JSON 类型。

原生主色改为中性色，工作流支持浅深两套面板配色。节点库收起按钮位于节点库标题旁；返回总览位于左上角；错误和操作结果经全局通知显示。截图额外覆盖 `workflow-*-library.png`、`workflow-*-variables.png` 和 `workflow-*-dropdown.png`。

## 图标工具栏与运行结果

`chrome.rs` 统一返回、工具栏、缩放控件、悬停说明及设置列表；窄窗口将工具栏移到第二行。条件出口使用随画布缩放的勾选 / 叉号图标，并保留两个独立连线目标。首次打开复杂流程优先保证节点可读，完整流程可通过适配按钮及缩略图查看。

`results.rs` 提供固定标题的历史列表及独立滚动的运行结果抽屉。开始运行后默认显示整体结果，实时刷新状态、输出、错误和节点列表；选择节点查看其输入、输出和耗时。成功的写入节点及结构化输出中的文档路径生成可点击卡片，文件内容提供摘要，点击复用项目现有文件查看器。原始 JSON 分页展示，复制始终包含完整结果。

回归包含实际执行条件分支和 Markdown 写入、无需选择节点即可看到结果、打开生成文档、缺失文件反馈、历史滚动隔离及条件端口缩放。对应截图为 `workflow-*-completed-result.png`、`workflow-*-node-result.png`、`workflow-*-history-list.png` 和 `workflow-*-settings-list.png`。
